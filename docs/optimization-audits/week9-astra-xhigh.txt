## Required fixes, in priority order

### R1 — Make the premise of compass exercise 3 consistent with the chapter's function

**Priority: high. Location: 9.5, lines 503–506.**

The exercise says the method is at `(2,3)` with `Delta=1/2` and none of the four neighbors has a lower value. But 9.0 says the same function is used throughout, and for that function:

| Point | Function value |
|---|---:|
| `(2,3)` | 32 |
| `(2.5,3)` | 23.3125 |
| `(1.5,3)` | 45.3125 |
| `(2,3.5)` | 64.8125 |
| `(2,2.5)` | 21.8125 |

Thus the actual rule moves to `(2,2.5)` and retains the step. A student checking the stated premise encounters a contradiction. Although the exercise does not repeat the formula, introducing an unnamed different function is insufficiently clear in this chapter.

**Minimal fix:** use `(3,2)` and retain `Delta=1/2`; the answers then become coordinates `3,2` and step `1/4`. Alternatively explicitly provide another function for which the stated premise is true. The first choice maintains the common example.

### R2 — Give numerical worked examples for the two halving decisions before the exercises

**Priority: high for the user's sole-textbook/example requirement. Locations: 9.2 and 9.4.**

The successful compass branch has a complete numerical example. The unsuccessful branch currently has an algorithmic statement and a final execution result, but no explicit numerical round connecting “no improvement” to “same point, smaller step.” Add a short worked case in 9.2, such as a round at `(3,2)`, whose value is zero and whose four nonzero neighbor values cannot improve it. State the actual old and new step and unchanged point. This prepares both 9.5.3 and Python exercise 2.

More importantly, Armijo is introduced by its formula and a long implementation, followed by overall convergence results. There is no worked substitution into the threshold, rejection, or first accepted factor before 9.5.5 and Python exercise 3. A code execution alone leaves the central comparison implicit.

**Minimal Armijo addition:** use the already worked start `z=(0,0)`, direction `p=(14,22)`, and slope `-680`. First show

`170 + 10^(-4) alpha (-680) = 170 - 0.068 alpha`.

Then a compact table can show the actual first search:

| Factor alpha | Actual candidate value | Armijo threshold | Decision |
|---|---:|---:|---|
| 1 | 283930 | 169.932 | Reject and halve |
| 1/2 | 17042 | 169.966 | Reject and halve |
| 1/4 | 761.125 | 169.983 | Reject and halve |
| 1/8 | 32.2578125 | 169.9915 | Accept |

Conclude that the first accepted point is `(7/4,11/4)` and that acceptance establishes sufficient decrease, not the minimum on the line. The long substitution into the polynomial, if included, belongs in a `reading-step` detail; the decision and a short substitution belong in the main reading path. Do not add a prediction question.

### R3 — Distinguish the outer method's stopping rule from the inner line search

**Priority: medium. Location: 9.4, lines 298–301.**

“Halveringsmetoden stopper når ... gradientnorm ... eller ... iterasjonsbudsjettet” follows the definition of an Armijo search and can imply that the halving loop stops on the gradient norm. The actual inner loop stops when the Armijo inequality holds. The outer gradient method stops on gradient norm or the iteration limit.

**Minimal fix:** say “Gradientmetoden med Armijo-steg stopper ...” and explicitly retain “Halveringen i hvert linjesøk stopper så snart Armijo-testen er oppfylt.” This makes the two algorithm levels explicit without adding material.

### R4 — Correct the explanation of independent samples

**Priority: medium. Location: 9.1, lines 57–61.**

The current explanation of independent points as points not chosen from previous *function values* defines non-adaptive sampling, not independence. A correlated random walk could ignore all previous function values and still have dependent points.

**Minimal fix:** explain that a new point is drawn independently of the previously drawn points, and that the example draws uniformly in the square. A plain-language explanation such as “ingen del av kvadratet favoriseres” is enough; no probability theory is needed. Identify 42 as the generator's seed, which reproduces the draws, rather than a spatial startpoint.

### R5 — Make the exact field for the lower bound mathematically unique

**Priority: medium. Location: 9.5.6, lines 555–559.**

“En global nedre grense” allows every number less than or equal to zero, whereas the answer field accepts only zero. The later proof request suggests the intended tight bound, but the field itself should not reject a valid answer to the literal question.

**Minimal fix:** ask for “en global nedre grense som oppnås i `(3,2)`,” or for the greatest lower bound. The former directly reinforces the certificate argument and avoids introducing additional vocabulary.

## Pedagogical structure and load

The principal sequence is well chosen: finite samples → adaptive compass search → derivative direction → controlled step. The distinction between direction and step length is explicit, and the connection to the SPD quadratic in week 6 is accurate. Prerequisite gradient, norm, stationary point, level curve, and residual are established in weeks 6/8, so they do not require first-principles reintroduction here. Preview names in the overview/learning goals are not a substantive teaching dependency.

The examples in 9.1 and 9.2 have clear experiments, stated observations, and discussion of their limits. The gradient section appropriately refreshes the necessary theory before its numerical step. In 9.4 the missing hand-worked Armijo comparison causes a jump from formula into about 70 lines of method/plotting code. R2 repairs that jump without increasing the conceptual scope.

Compared with the approved week 8, week 9 places longer runnable examples in the main path instead of collecting them in 9.6. That is an acceptable experiment-led organization, but add a short reading guide in 9.0 if desired: the code can be run, while printed results and accompanying prose explain the conclusions; 9.5 is hand calculation and 9.6 is short completion practice. Do not require students to understand the plotting mechanics before they understand the method.

The three Python exercises have appropriate introductory load: complete two lines, receive supplied function definitions, and practice one task at a time. They do not require implementing a general solver, reading another cell's state, or predicting results. Several hand tasks repeat the worked numbers exactly. This is fine for a first practice set, although varying the start or factor in one later task would improve transfer. It is optional, not a reason to expand the week.
