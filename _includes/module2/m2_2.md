### Spindelvevplott

En liste med iterater viser tallene, men ikke hvordan formen på $g$ styrer bevegelsen. Et **spindelvevplott** gjør hvert steg synlig og lar oss sammenligne banen med skjæringspunktene mellom $y=g(x)$ og $y=x$. Disse skjæringspunktene er fikspunktene.

1. Gå loddrett til $y=g(x)$; høyden er $x_{n+1}=g(x_n)$.
2. Gå vannrett til $y=x$; den nye $x$-koordinaten er $x_{n+1}$.
3. Gjenta.

```{pyodide-python}
def cobweb_plot(g, x0, number_of_steps=20,
                x_min=0, x_max=1, title="Spindelvevplott"):
    x_grid = np.linspace(x_min, x_max, 800)
    y_grid = np.array([g(x) for x in x_grid])
    values = iterate(g, x0, number_of_steps)

    plt.close("all")
    fig, ax = plt.subplots(figsize=(7, 7))
    ax.plot(x_grid, y_grid, label="$y=g(x)$")
    ax.plot(x_grid, x_grid, "k--", label="$y=x$")

    current = values[0]
    for next_value in values[1:]:
        ax.plot([current, current], [current, next_value], color="tab:red")
        ax.plot([current, next_value], [next_value, next_value], color="tab:red")
        current = next_value

    ax.set(xlim=(x_min, x_max), ylim=(x_min, x_max),
           xlabel="$x$", ylabel="$y$", title=title)
    ax.set_aspect("equal", adjustable="box")
    ax.grid(True)
    ax.legend()
    plt.show()
    return values
```

```{pyodide-python}
values = cobweb_plot(g1, 0.5, 20, 0, 1, "$g_1(x)=1-x^3$")
```

```{pyodide-python}
values = cobweb_plot(g2, 0.5, 20, 0, 1, "$g_2(x)=\\sqrt[3]{1-x}$")
```

```{pyodide-python}
values = cobweb_plot(g3, 0.5, 8, 0, 1, "$g_3$")
```

### Undersøk metoden

Endre én størrelse om gangen: funksjonen, startverdien, intervallet eller antall steg. Blir avstanden til fikspunktet mindre eller større? Ligger iteratene vekselvis på hver side? Gjentas de samme to eller flere verdiene? Prøv også flere steg før du konkluderer med at følgen ikke konvergerer.

::: {.callout-tip}
Et plott kan avdekke mønstre, foreslå hypoteser og finne moteksempler. Det undersøker bare de valgte startverdiene og antall iterasjoner og er derfor ikke et bevis.
:::

### Helningsregelen

Plottet antyder om nærliggende iterater trekkes mot eller skyves bort fra et fikspunkt. For å forklare dette uten å teste mange startverdier ser vi på den lokale helningen. Et fikspunkt er **attraktivt** dersom startverdier tilstrekkelig nær det beveger seg mot det. Det er **frastøtende** dersom nærliggende startverdier beveger seg bort.

Hvis $x_n=r+e_n$, er $e_n$ feilen. Nær et glatt fikspunkt får vi omtrent

$$e_{n+1}\approx g'(r)e_n,$$

og dermed

$$|e_{n+1}|\approx |g'(r)|\,|e_n|.$$

::: {.callout-important}
#### Lokal helningsregel

- $|g'(r)|<1$: attraktivt fikspunkt.
- $|g'(r)|>1$: frastøtende fikspunkt.
- $|g'(r)|=1$: regelen avgjør ikke.

Regelen gjelder lokalt, altså for startverdier nær $r$.
:::

Fortegnet forklarer også formen: positiv helning gir ofte tilnærming fra én side; negativ helning gir ofte kryssing fram og tilbake.

For eksemplet får vi analytisk

$$|g_1'(r)|\approx1.40,\qquad |g_2'(r)|\approx0.72,\qquad g_3'(r)=0.$$

For $g_1$ blir en liten feil lokalt multiplisert med omtrent $1.40$ og vokser derfor. For $g_2$ blir omtrent $72\%$ av feilen igjen per iterasjon. For $g_3$ er den lineære faktoren null; feilen avtar med høyere orden nær fikspunktet.
