### Implementasjon og diagnostikk

En formel alene er ikke en ferdig algoritme. Programmet trenger en startverdi, en stoppregel og en grense som hindrer at en divergent eller syklisk følge kjører for alltid. Det må også returnere nok informasjon til at vi kan kontrollere hva stoppregelen faktisk målte. Derfor returnerer funksjonen stoppårsak, iterasjonstall, historikk, skrittlengder og residualer i tillegg til siste verdi.

```{pyodide-python}
import math

def fixed_point(g, x0, f=None, atol=1e-10, rtol=1e-10, maxiter=100):
    """Fikspunktiterasjon x_(n+1)=g(x_n), med diagnostikk."""
    x = float(x0)
    history = [x]
    steps = []
    fp_residuals = [abs(g(x) - x)]
    f_residuals = None if f is None else [abs(f(x))]

    for iteration in range(1, maxiter + 1):
        x_new = g(x)

        if not math.isfinite(x_new):
            return {"x": x_new, "converged": False,
                    "reason": "ikke-endelig verdi", "iterations": iteration,
                    "history": np.array(history), "steps": np.array(steps),
                    "fp_residuals": np.array(fp_residuals),
                    "f_residuals": f_residuals}

        step = abs(x_new - x)
        history.append(x_new)
        steps.append(step)
        fp_residuals.append(abs(g(x_new) - x_new))
        if f is not None:
            f_residuals.append(abs(f(x_new)))

        tolerance = atol + rtol*abs(x_new)
        if step <= tolerance:
            return {"x": x_new, "converged": True,
                    "reason": "lite skritt", "iterations": iteration,
                    "history": np.array(history), "steps": np.array(steps),
                    "fp_residuals": np.array(fp_residuals),
                    "f_residuals": (None if f_residuals is None
                                    else np.array(f_residuals))}
        x = x_new

    return {"x": x, "converged": False,
            "reason": "maksimalt antall iterasjoner", "iterations": maxiter,
            "history": np.array(history), "steps": np.array(steps),
            "fp_residuals": np.array(fp_residuals),
            "f_residuals": (None if f_residuals is None
                            else np.array(f_residuals))}
```

```{pyodide-python}
def f(x):
    return x**3 + x - 1

result = fixed_point(g2, 0.5, f=f, atol=1e-12, rtol=1e-12, maxiter=200)
print("Tilnærming: ", result["x"])
print("Konvergerte:", result["converged"])
print("Stoppårsak: ", result["reason"])
print("Iterasjoner:", result["iterations"])
print("Residual:    ", result["f_residuals"][-1])
```

Prøv først `maxiter=10` og noter stoppårsak og siste residual. Prøv deretter `g1` og `rtol=1e-20` hver for seg. Oppfylles den kombinerte skrittlengdegrensen, eller stopper programmet av en annen grunn? Uten `maxiter` kan en divergent eller syklisk metode kjøre for alltid. `nan` og `inf` skal behandles som feil, ikke som konvergens.

### Et historisk eksempel: kvadratrøtter

For å beregne $\sqrt a$ kan vi løse $x^2-a=0$. Omskrivningen $x=a/x$ gir

$$x_{n+1}=\frac{a}{x_n}.$$

```{pyodide-python}
a = 2
def g_bad(x):
    return a/x

print(iterate(g_bad, 1, 10))
```

Følgen går i syklusen $1,2,1,2,\ldots$, så skrittlengden blir aldri mindre enn $1$. For å få en oppdatering som demper denne vekslingen, tar vi gjennomsnittet av $x$ og $a/x$:

$$x_{n+1}=\frac12\left(x_n+\frac{a}{x_n}\right).$$

```{pyodide-python}
def make_sqrt_iteration(a):
    def g(x):
        return 0.5*(x + a/x)
    return g

def make_sqrt_equation(a):
    def f(x):
        return x*x - a
    return f

g_sqrt = make_sqrt_iteration(2)
f_sqrt = make_sqrt_equation(2)
result_sqrt = fixed_point(g_sqrt, 1, f=f_sqrt,
                          atol=1e-15, rtol=1e-15)

for n, x in enumerate(result_sqrt["history"]):
    print(f"n={n:2d}: x={x:.16f}, |x²-2|={abs(x*x-2):.3e}")
```

I $r=\sqrt a$ er $g'(r)=0$, og metoden konvergerer kvadratisk nær løsningen.

```{pyodide-python}
values = cobweb_plot(g_sqrt, 1, 7, 0.5, 2,
                     "Fikspunktiterasjon for kvadratroten av 2")
```

Til slutt blir forbedringen mindre enn avstanden til neste representerbare binary64-tall. Da kan neste verdi avrundes til samme flyttall, skrittlengden bli null og flere iterasjoner gi nøyaktig samme lagrede verdi.

### Oppsummering

1. Et fikspunkt oppfyller $g(r)=r$.
2. Konvergens betyr at tilnærmingene nærmer seg og stabiliserer seg rundt én verdi.
3. Pendling kan konvergere, divergere eller danne en syklus.
4. Attraktive fikspunkt trekker nærliggende verdier til seg; frastøtende skyver dem bort.
5. $|g'(r)|<1$ gir en lokal forventning om konvergens.
6. Lokal konvergens gjelder nære startverdier; global konvergens gjelder alle startverdier i et oppgitt område.
7. Ved lineær konvergens er $|e_{n+1}|/|e_n|\approx S$; ved kvadratisk konvergens er $|e_{n+1}|/|e_n|^2\approx C$ nær løsningen.
8. Absolutt feil måler avstand; relativ feil måler feil i forhold til svarets størrelse.
9. Sann feil er vanligvis ukjent. Residual og skrittlengde kan beregnes, men svarer på andre spørsmål.
10. `atol` er en absolutt akseptgrense; `rtol` skalerer kravet med størrelsen på svaret.
11. En toleranse er et stoppkrav, ikke en garanti for like liten sann feil.
12. Binary64 har omtrent 15–16 signifikante desimalsifre; en strengere toleranse kan ikke skape mer representerbar informasjon.
13. En nyttig numerisk funksjon returnerer diagnostikk, ikke bare ett tall.

### Hovedlærdom

En numerisk algoritme er en formel sammen med en startverdi, et konvergensområde, et mål på framgang, et stoppkriterium og en måte å oppdage feil på. Python lar oss undersøke valgene; analyse forklarer observasjonene.
