### Hvorfor iterative metoder?

Mange problemer i informatikk og ingeniørfag ender med en ligning

$$
f(x)=0.
$$

Det kan for eksempel være en verdi som gir likevekt i en simulering, et tidspunkt der to bevegelser møtes, eller en parameter som får en modell til å passe med observerte data.

Noen ganger finnes en praktisk formel for løsningen. Ofte gjør den ikke det. Da trenger vi en prosedyre som en datamaskin kan gjenta:

1. Start med et anslag $x_0$.
2. Bruk anslaget til å lage et nytt anslag $x_1$.
3. Bruk $x_1$ til å lage $x_2$.
4. Fortsett og undersøk om anslagene nærmer seg en løsning.

Dette er en svært vanlig idé i numerikk: Vi erstatter spørsmålet «kan vi skrive ned løsningen direkte?» med spørsmålet «kan vi lage en oppdateringsregel som beveger oss mot løsningen?»

### Et testproblem

Som et kontrollert eksperiment bruker vi

$$x^3+x-1=0.$$

La

$$f(x)=x^3+x-1.$$

Før vi lager en metode, undersøker vi problemet med Python.

```{pyodide-python}
import numpy as np
import matplotlib.pyplot as plt

def f(x):
    return x**3 + x - 1

x_grid = np.linspace(0, 1, 400)

plt.close("all")
fig, ax = plt.subplots()
ax.plot(x_grid, f(x_grid), label="$f(x)=x^3+x-1$")
ax.axhline(0, color="black", linewidth=1)
ax.set_xlabel("$x$")
ax.set_ylabel("$f(x)$")
ax.set_title("Hvor ligger løsningen?")
ax.grid(True)
ax.legend()
plt.show()

print("f(0) =", f(0))
print("f(1) =", f(1))
```

Grafen og fortegnene viser at en løsning ligger mellom $0$ og $1$. Siden

$$
f'(x)=3x^2+1>0,
$$

er funksjonen strengt voksende og kan derfor ikke ha mer enn én løsning. Vi har altså ett tydelig mål for eksperimentet.

En svært nøyaktig referanseverdi er

$$r\approx0.6823278038.$$

Referanseverdien skal ikke brukes av algoritmen. Vi bruker den senere til å måle feil og undersøke hvor raskt ulike metoder nærmer seg løsningen.

### Fra ligning til oppdateringsregel

En mulig strategi er å omskrive ligningen til

$$
x=g(x)
$$

og deretter gjenta høyresiden:

$$
x_{n+1}=g(x_n).
$$

Dette er et bevisst designvalg, ikke et tilfeldig algebraisk triks. For testproblemet kan vi konstruere flere mulige oppdateringsregler:

$$x=1-x^3,\qquad x=\sqrt[3]{1-x},\qquad x=\frac{2x^3+1}{3x^2+1}.$$

Definer høyresidene som $g_1$, $g_2$ og $g_3$. Alle er konstruert slik at løsningen oppfyller

$$
r=g_i(r).
$$

Dermed har alle tre samme mål. Nå undersøker vi om de også er like gode veier til målet.

```{pyodide-python}
def g1(x):
    return 1 - x**3

def g2(x):
    # Reell kubikkrot, også for negative argumenter
    return np.cbrt(1 - x)

def g3(x):
    return (2*x**3 + 1)/(3*x**2 + 1)

def iterate(g, x0, number_of_steps):
    """Returner x_0, x_1, ..., x_n."""
    values = [float(x0)]
    for _ in range(number_of_steps):
        values.append(g(values[-1]))
    return np.array(values)
```

```{pyodide-python}
solution = 0.6823278038280193

plt.close("all")
fig, ax = plt.subplots()
for g, label in [(g1, "$g_1$"), (g2, "$g_2$"), (g3, "$g_3$")]:
    values = iterate(g, 0.5, 30)
    print(label, values[:8], "...", values[-1])
    ax.plot(values, marker=".", label=label)

ax.axhline(solution, color="black", linestyle="--", label="løsningen")
ax.set_xlabel("Iterasjon $n$")
ax.set_ylabel("Tilnærming $x_n$")
ax.set_title("Én ligning, tre algoritmer")
ax.grid(True)
ax.legend()
plt.show()
```

### Undersøk før du leser videre

- Hvilke følger nærmer seg løsningen?
- Hvilken ser raskest ut?
- Hvilken pendler?
- Er pendling alltid det samme som at metoden mislykkes?
- Endres konklusjonen hvis du endrer startverdien?

::: {.callout-important}
### Hovedidé

Å omskrive en ligning er ikke bare algebra. Valget av $x=g(x)$ bestemmer den numeriske algoritmen. Ekvivalente formler kan gi helt forskjellig oppførsel.
:::
